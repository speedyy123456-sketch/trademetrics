GUÍA RÁPIDA

¿Cómo usar la herramienta?

Prepara el historial correcto en pocos pasos y deja que TradeMetrics haga el análisis por ti.

Opción 1 · Cargar un Excel

  1. 01

    Paso 1

    Ve a tu exchange, entra a Futuros > Historial de Órdenes / Posiciones Cerradas y localiza el reporte que quieres analizar.

  2. 02

    Paso 2

    Exporta el reporte en formato .xlsx o .xls (Excel), seleccionando el rango de fechas que deseas revisar.

  3. 03

    Paso 3

    Selecciona el exchange en la plataforma y pulsa Seleccionar Excel de posiciones. El archivo se procesa en tu navegador.

Opción 2 · Consultar MEXC por API

  1. 01

    Paso 1

    En MEXC crea una API key con el permiso View Order Details únicamente. Es un permiso de solo lectura; no actives trading ni retiros.

  2. 02

    Paso 2

    Selecciona MEXC, ingresa tu API Key y Secret Key en Conectar API de MEXC y pulsa Consultar posiciones cerradas.

  3. 03

    Paso 3

    TradeMetrics consulta tus posiciones cerradas y muestra el mismo dashboard. Las claves se envían por HTTPS a Netlify y se procesan temporalmente, sin guardarse.

AYUDA

Preguntas Frecuentes

¿Mis datos están seguros?

Los archivos Excel se leen en tu navegador. Si conectas MEXC, la API Key y Secret Key se envían por HTTPS a una función de Netlify, que las procesa en memoria para firmar solicitudes de lectura. TradeMetrics no las guarda. Crea una clave MEXC con permiso de lectura únicamente.

¿Es completamente gratuito?

Sí, la herramienta es y seguirá siendo gratuita para análisis de historiales de futuros.

¿Qué hago si mi archivo da error?

Asegúrate de exportar el historial de posiciones cerradas de futuros y no el de billetera Spot o depósitos. Si el problema persiste, puedes reportarlo desde el enlace de soporte en el footer.

¿Puedo subir archivos de varios exchanges a la vez?

Por el momento debes seleccionar el exchange correspondiente y cargar el archivo individualmente para garantizar la correcta lectura del formato.
